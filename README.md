# Gurukul School Management System

Full-stack school management system structure.

## Applications
- `client/` - React + Vite frontend
- `server/` - Node.js + Express backend
- `database/` - MySQL migrations, seeds, and schema

## Setup

### Client
```bash
cd client
npm install
npm run dev
```

### Server
```bash
cd server
npm install
cp .env.example .env
npm run dev
```

Do not commit `.env` files or real credentials. Use `.env.example` as the template.
